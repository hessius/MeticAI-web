# MeticAI Web Interface — Archived

> **This repository has been archived.** The web interface has been merged into the main [hessius/MeticAI](https://github.com/hessius/MeticAI) repository as of February 2026.

## What happened

The MeticAI project originally consisted of two separate repositories:
- `hessius/MeticAI` — the backend relay server and infrastructure
- `hessius/MeticAI-web` — the React/TypeScript web interface (this repo)

To simplify development and reduce the overhead of keeping two repositories in sync, the web interface source code was merged into the main `hessius/MeticAI` repository under `apps/web/`.

## Where to go

- **Main repository**: https://github.com/hessius/MeticAI
- **Web interface source**: https://github.com/hessius/MeticAI/tree/main/apps/web
- **Issues and contributions**: Please open issues and PRs in the main repository

## Historical reference

This repository is preserved as a historical reference. The last active commit was in February 2026 before the merge.
